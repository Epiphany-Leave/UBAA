# Android 手机日历人工验收

在实体手机安装当前 ARM64 测试 APK。以下操作无需为测试真实选课；创建的测试日程可在系统日历中删除。Pixel 8 轻度验证不能代替以下边界验收。

| 项目 | 操作 | 预期 |
| --- | --- | --- |
| 个人日程冲突 | 博雅课程详情记下上课时间，在系统日历创建同时间段的测试事件，点击“检测日程冲突”并授权 | 显示标题、起止时间、地点、所属日历；不禁止用户自行选课 |
| 时间边界 | 将测试事件开始时间改为课程结束时间后重新检测 | 首尾相接不算冲突 |
| 课程日程 | 从“我的课程”进入详情，点“添加课程日程” | 系统编辑页预填课程名称、起止时间、地点，用户确认保存 |
| 取消保存 | 在系统编辑页返回并放弃保存 | 日历无新增记录，UBAA 不报告添加成功 |
| 预告提醒 | 预告课程详情点“添加选课提醒” | 以开放选课时间开始、持续 5 分钟；Android 必须在编辑页人工确认提前 5 分钟提醒 |
| 通知 | 将测试提醒改到几分钟后保存，并允许系统日历通知 | 通知由系统日历触发，不由 UBAA 后台定时器触发 |
| 拒绝或撤销权限 | 拒绝读取或在系统设置撤销后再次检测 | 提示未完成检测，不能报告无冲突，原有选课功能仍可使用 |
| 重复、全天、跨天 | 分别创建覆盖课程时段的测试事件 | 展示对应日期的重叠实例；空闲事件单独标注 |
| 缺少时间 | 进入没有有效时间的课程并尝试日历操作 | 明确无法检测或添加，不猜测时间 |

Android 无可靠保存回执，打开编辑页不是保存成功证明，须返回系统日历确认。未有已选或预告课程时对应项目记为未验，不能计为通过。个人日历不写入应用诊断，不必将日程截图或内容提交到仓库。

目前：用户此前在 Pixel 8 轻度测试通过；实体手机完整测试、iOS/Mac 构建及 iPhone 验收未确认。
