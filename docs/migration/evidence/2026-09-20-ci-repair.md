# UBAA2 上传与 CI 修复

本轮汇总已在 Pixel 8 轻度验证的 ui25 日历功能及此前组件、外观设置。目标为 Epiphany-Leave/UBAA 的 `UBAA2` 分支。

## 失败原因与修复

- 上次运行 35447689740：Dart 格式、两份超长文件、五项 Rust Clippy 告警分别阻塞四个任务。保留检查强度，格式化并按现有 part 边界拆分文件。
- 后续回归发现旧 UI 测试仍使用迁移前的筛选栏、字段下标和返回按钮。改用当前入口及字段标签，保留 typed 参数、取消、失败关闭、结果不确定和重复提交保护断言。
- 截图基线更新为目前界面；首页和空教室截图固定日期，避免每天变动。截图使用 Flutter 测试默认字体，仅用于布局回归。
- CLI JSON schema 补齐现有博雅详情字段；FRB 元数据预检使用 `--locked`；Windows 路径断言和引用脚本本地测试统一原生路径表示。
- 博雅写前复核必须拒绝缺失 selected 的资格，不能复用详情展示的默认未选状态。原有 `write_authority` 测试覆盖该边界；不新增学校接口，不改变本科/研究生分流。有效选课仍需明确资格和用户确认。

## 验证

Windows 本地：Rust workspace/all-targets 768 通过、2 项既有真实环境测试跳过；七个 Dart/Flutter package 共 447 项通过，全部 analyze 通过。Clippy 全 workspace/all-targets/all-features 严格检查、Core 关闭默认 feature、facade 注入开关编译合同、refs、结构检查与敏感扫描通过；FRB 重新生成零差异。

`just check` 的 Shell 自测在 Windows 因缺少 `zip` 停止，没有安装新工具；完整严格门禁由 GitHub Ubuntu 执行。独立编译夹具的 Cargo.lock 已同步现有 fs2 依赖。上次记录的引用路径问题已修正。

截图沿用 CI 的 macOS 渲染环境。失败时额外生成候选截图供核对，不更改失败状态、不自动提交候选图、不降低比较精度。远端验证以本分支最新提交的四项 CI 结果为准。

已核对 CI 35484189412（源码 9214910）生成的 26 张 macOS 候选截图，更新对应基线。覆盖手机/平板/桌面明暗主题、首页及各功能页；Windows 同一截图存在少量平台渲染差异，逐像素验收以 macOS CI 为准。

APK、个人测试数据和本机工具不提交。Pixel 8 轻度验证不替代 iOS/Xcode 或其他系统的原生构建验收。
