# 应用语言（ui26）

“我的 → 语言”提供跟随系统、简体中文、繁體中文、English。默认跟随系统；旧设置和未知保存值兼容为跟随系统。显式选择立即生效并复用 ui-appearance.json 持久化，不绑定账号。设置保存失败保留本次选择并提示重试。

共享 Flutter 宿主设置 locale、supportedLocales、localizationsDelegates 和 localeListResolutionCallback。中文按 Hans/Hant 区分；无脚本的 TW/HK/MO 使用繁体，其他中文使用简体。遍历系统首选语言，均不支持时回退简体。系统日期选择器等复用 Flutter SDK 的 flutter_localizations；intl 0.20.2 来自现有缓存，pub get --offline 完成，未安装工具。

UI 增加 599 条英语/繁体文案，覆盖导航、个人设置、登录、功能入口、筛选、课程/考试/成绩、预约、日历操作及公共错误提示。参数仅替换占位符一次，不翻译学校课程名称、地点、教师、账号、个人日历正文；也不改变用中文字段名读取既有 FeatureDetail 的逻辑。Core、facade、bridge 学校调用和本科/研究生分流未改变。学校返回内容、Core 生成的业务原文和原生桌面组件不做自动翻译；系统日历编辑页遵循系统自己的语言。

本次为展示层修改：无新增学校端点、请求参数、Cookie 或会话改动；无需重新借用参考系统协议。冻结引用验证通过。iOS 声明支持的三种语言，未修改最低系统版本；Windows 不能验收 iOS/macOS/HarmonyOS 原生构建。

## Pixel 8 手动验收

1. 覆盖安装 ui26，打开“我的 → 语言”，依次切换四项；查看导航、课表、筛选和日期选择器。
2. 选择 English 后完全退出再打开，确认仍是英语；选择繁體中文同样验证。
3. 选择跟随系统，在 Pixel 8 系统设置更改语言后返回应用；显式选择简体中文时更改系统语言应保持简体。
4. 课程名、教室、个人日程等原文不应被改写；查询、选课和预约行为保持原样。本轮不代用户提交实际学校写请求。
